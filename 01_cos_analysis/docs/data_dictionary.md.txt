# 📊 Dictionnaire de Données - COS Synthétique

## 📅 Vue d'ensemble
- **Période** : 180 jours (6 mois)
- **Fréquence** : Quotidienne
- **Restaurants** : 10 (identifiés 1 à 10)
- **Produits** : 8 familles principales + variations
- **Enregistrements** : ~14,400 lignes

| Colonne | Type | Description | Valeurs exemple | Règles |
|---------|------|-------------|-----------------|---------|
| `transaction_id` | INT | Identifiant unique | 10001, 10002 | Auto-incrément |
| `date` | DATE | Date de transaction | 2024-01-15 | Format YYYY-MM-DD |
| `restaurant_id` | INT | ID restaurant | 1 à 10 | 10 restaurants fictifs |
| `restaurant_name` | VARCHAR | Nom restaurant | "KFC Paris Louvre" | Déduit de l'ID |

## 📈 KPI Calculés (dérivés)

| KPI | Formule | Description | Cible |
|-----|---------|-------------|-------|
| `revenue` | `selling_price × units_sold` | Chiffre d'affaires | - |
| `theoretical_cos` | `(theoretical_cost × units_sold) / revenue` | COS théorique (%) | 38-42% |
| `actual_cos` | `(actual_cost × units_sold) / revenue` | COS réel (%) | - |
| `cos_gap` | `actual_cos - theoretical_cos` | Écart absolu | < 2% |
| `gap_percentage` | `cos_gap / theoretical_cos × 100` | Écart relatif (%) | < 5% |
| `waste_cost` | `waste_kg × theoretical_unit_cost` | Coût du gaspillage | Minimiser |
| `profit_margin` | `(revenue - actual_cost) / revenue × 100` | Marge bénéficiaire | > 15% |
| `gap_severity` | `CASE WHEN gap_percentage > 10 THEN 'CRITIQUE' WHEN > 5 THEN 'ÉLEVÉ' ELSE 'NORMAL' END` | Niveau de sévérité | - |

## 🔄 Logique de Génération Synthétique

### **Écarts simulés réalistes :**
1. **Variations saisonnières** :
   - +15% ventes en weekend
   - +20% pendant vacances scolaires
   - -10% en période de grève/météo

2. **Impact opérationnel** :
   - **Managers expérimentés** : écart COS -1% à -3%
   - **Équipement récent** : gaspillage -15%
   - **Score QSP élevé** : conformité recette +10%

3. **Anomalies types** :
   - **Surconsommation** : +25% coût réel (portion trop généreuse)
   - **Sous-cuisson** : gaspillage +30% (produit jeté)
   - **Erreur inventaire** : -20% ventes (rupture)
   - **Vol** : écart inexplicable 5-15%

### **Distributions par famille produit :**

| Sandwichs | 2.80 € | 5-8% | 0.5 kg | Moyenne |
| Burgers | 3.10 € | 6-10% | 0.7 kg | Moyenne |
| Accompagnements | 1.50 € | 3-5% | 2.5 kg | Faible |
| Boissons | 0.80 € | 1-3% | 0.1 kg | Très faible |

## 🎯 Points de Contrôle Réalistes

1. **Recette standard** : Pesée précise à ±5g
2. **Température cuisson** : 175°C ±5°C
3. **Temps de maintien** : < 30 minutes avant jet
4. **Formation équipe** : 4h/mois minimum
5. **Audit interne** : 1 fois/semaine
